## Brinkman volume penalization and PhD code

This organization holds the code of my PhD (Sorbonne Université, LOCEAN and Inria) and of the Brinkman volume penalization (BVP) work that grew out of it.
Repositories are kept as published, so links in papers keep working. Thesis-era repositories are frozen and not maintained.

This is not my main account: current work lives at [@antoinenasser](https://github.com/antoinenasser) · [antoinenasser.github.io](https://antoinenasser.github.io)

### BVP for ice-shelf cavities: Nasser et al. (2026)
[preprint](https://doi.org/10.22541/essoar.176677323.32970185/v2)

- [bvp_isomip_Nasser2026](https://github.com/antoine-182/bvp_isomip_Nasser2026): published version, BVP in NEMO 4.2 with the ISOMIP+ configuration
- [my_isomip](https://github.com/antoine-182/my_isomip): development version, may change

### BVP along topography: PhD thesis (2023)
[thesis](https://theses.hal.science/tel-04399405)

- [penalnemov4.0.1](https://github.com/antoine-182/penalnemov4.0.1): penalization in NEMO 4.0.1 as published with the thesis, including the overflow configuration
- [penalorcav4.2.0](https://github.com/antoine-182/penalorcav4.2.0): penalized global ORCA1 configuration (NEMO 4.2.0) as published with the thesis
- [am98-topography](https://github.com/antoine-182/am98-topography): penalization compared with topography in a reduced-gravity shallow-water basin (AM98), from NEMO 4.0
- [bvp_topography](https://github.com/antoine-182/bvp_topography): beta-topography effect in the same AM98 basin
- [python_penaloverflow](https://github.com/antoine-182/python_penaloverflow): notebooks for the overflow test case with penalization
- [python_local_phd](https://github.com/antoine-182/python_local_phd): Jupyter notebooks from the PhD

### Staircase coastlines: Nasser et al. (2023), JAMES
[doi:10.1029/2022MS003594](https://doi.org/10.1029/2022MS003594)

- [staircaseNEMO](https://github.com/antoine-182/staircaseNEMO): NEMO code for the simulations
